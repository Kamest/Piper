Piper is for the moment an agent reaches outside its project.

Running several agents side by side is common now, and many tools do it well, most with more agents and more polish than Piper. They differ in what happens when an agent goes for something that is not its working copy: your keys, production data, a push, a host on the internet. Piper is built around that moment.

Checked on 2026-10-24 against each project's own docs. Tell us when something here is out of date.

Three moments

Most local workspaces give each agent a git worktree and run it as you. That keeps parallel tasks from editing each other's files. It does not change what the agent can reach. Here is the same action in both setups.

agent runs cat ~/.ssh/id_ed25519

Piper

The file is not there. Each session's container mounts its project, not your home directory, and the paths you exclude, such as .env, are masked.

Worktree tool

The agent runs as you, so the file is readable. What stands in the way is the agent's own permission settings or its own sandbox, which is off by default in Claude Code.

agent queries SELECT email FROM customers on the production connection

Piper

A card from the Minimal preset up, with the SQL, the connection marked as production and the rule that asked. Reads of test data and writes to dev run on their own. Inside the container, a direct connection needs its host in the network allowlist.

Worktree tool

The agent uses whatever credentials it finds. Its permission rules match the command text, so they can tell psql from ls, not a test database from a production one.

agent runs git push origin main

Piper

Under Recommended, a card with the exact git arguments. Under Minimal it runs on its own and goes to the audit log. Either way it is one switch, not a pattern you maintain.

Worktree tool

The agent pushes with your credentials. You can deny git push with a Claude Code rule; Codex in on-request mode asks before any network use, a push or not.

The same holds for HTTP: requests to test, production or unknown hosts get a card, and outbound traffic from the container is filtered against your list of domains. Every decision, automatic ones included, is written to an audit log. Details and limits: security model.

When to pick something else

  • You want more than Claude Code and Codex. Orca, Emdash and Superset run many more agents.
  • You want the quickest start, or cannot run Docker. Any worktree tool starts in seconds; Piper builds a sandbox image on the first start, which takes minutes.
  • You are on macOS and want a polished app first. Conductor.
  • Work should go on with your laptop closed. Use a hosted agent below, or run Piper on a machine that stays on and reach it over your tailnet.
  • You need native Windows without WSL 2, or a mature tool. Piper is a 0.x release; its open checks are public.

Pick Piper when your agents work with real infrastructure, such as databases, pushes and other projects, and you want them to run on their own without approving every command.

Hosted agents

Claude Code on the web, Codex cloud and Cursor's cloud agents run each task in a VM or container in the vendor's cloud. They isolate well, and your code and the credentials a task needs live in that cloud.

  • Claude Code on the web: a VM per task, network None, Trusted, Full or Custom, git through a proxy that keeps credentials out of the VM. docs
  • Codex cloud: containers, internet off by default, with an allowlist. docs
  • Cursor cloud agents: isolated VMs with egress restrictions. docs

They fit work that suits a fresh clone in the cloud. Piper fits work that needs your local projects, databases, tunnels and tools.

The agents' own sandboxes

  • Claude Code can sandbox its Bash commands with a network allowlist. It is off by default, and its docs call it not a complete isolation boundary. docs
  • Codex CLI runs in workspace-write with the network off by default, and in on-request mode asks before writing outside the workspace or using the network. docs

Piper does not replace them. It adds a container around the whole session and asks about actions by what they touch.
