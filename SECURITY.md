# Security policy

Piper runs coding agents with access to your projects, so sandbox escapes, guard bypasses,
credential leaks and approval-card spoofing are security issues.

## Reporting a vulnerability

Report it privately through GitHub: **Security → Report a vulnerability** in this repository.
Do not open a public issue or pull request for it. Include the Piper commit, your OS, the
setting or guard involved and the smallest steps that reproduce it. Use synthetic data only;
never attach real tokens, session state or transcripts.

You get an acknowledgement within a week. Fixes land on `main`; there are no maintained
release branches yet.
